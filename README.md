# Portfolio – Huu Dat VU

Site statique (HTML/CSS/JS, un seul fichier + images) publié avec GitHub Pages.

## Mettre en ligne
1. Créez un dépôt public nommé **Corgi-coder99.github.io**.
2. Déposez `index.html` et le dossier `assets/` à la racine.
3. Settings → Pages → Source : *Deploy from a branch*, branche `main`, dossier `/ (root)`.
4. Le site sera disponible sur https://corgi-coder99.github.io/

## Ajouter votre photo
Placez `assets/photo.jpg`, puis dans `index.html` remplacez `<span>HV</span>` par
`<img src="assets/photo.jpg" alt="Huu Dat VU">`.
